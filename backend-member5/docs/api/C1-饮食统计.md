# C1 — 饮食统计

## 基本信息

| 项目 | 说明 |
|------|------|
| 方法 | `GET` |
| 路径 | `/api/statistics/{user_id}/food` |
| 功能 | 统计指定时间段内饮食数据：日均营养、三餐分布、热量趋势、高频食物 |
| 鉴权 | 无 |

---

## 请求参数

| 字段 | 类型 | 必填 | 位置 | 说明 |
|------|------|------|------|------|
| user_id | int | ✅ 是 | Path | 用户编号 |
| start_date | string | ✅ 是 | Query | 起始日期 `YYYY-MM-DD` |
| end_date | string | ✅ 是 | Query | 结束日期 `YYYY-MM-DD` |

### 请求示例

```text
GET /api/statistics/1/food?start_date=2026-07-10&end_date=2026-07-17
```

## 业务逻辑

```
1. 参数校验：日期格式 + start_date ≤ end_date
2. 查 v_daily_food_summary 获取每日汇总（total_calorie_kcal, total_protein_g, food_health_score）
3. 查 food_record JOIN food_library GROUP BY meal_type 获取三餐分布
4. 查 food_record JOIN food_library GROUP BY name ORDER BY cnt DESC LIMIT 5 获取高频食物
5. 计算 daily_avg、calories_trend
6. 生成 summary
```

### SQL（3 条查询）

```sql
-- 查询1：每日饮食汇总
SELECT intake_date, total_calorie_kcal, total_protein_g, food_health_score
FROM v_daily_food_summary
WHERE user_id = ? AND intake_date BETWEEN ? AND ?
ORDER BY intake_date;

-- 查询2：三餐分布
SELECT fr.meal_type,
       ROUND(SUM(fl.calorie_kcal * fr.amount / 100.0), 2) AS total_cal,
       COUNT(*) AS cnt
FROM food_record fr
JOIN food_library fl ON fl.food_id = fr.food_id
WHERE fr.user_id = ? AND fr.intake_date BETWEEN ? AND ?
GROUP BY fr.meal_type;

-- 查询3：高频食物 Top5
SELECT fl.name, COUNT(*) AS cnt
FROM food_record fr
JOIN food_library fl ON fl.food_id = fr.food_id
WHERE fr.user_id = ? AND fr.intake_date BETWEEN ? AND ?
GROUP BY fl.name
ORDER BY cnt DESC
LIMIT 5;
```

## 数据来源

| 数据 | 来源 |
|------|------|
| 每日营养汇总 | `v_daily_food_summary` 视图 |
| 三餐分布 | `food_record` JOIN `food_library`（原始表） |
| 高频食物 | `food_record` JOIN `food_library`（原始表） |

---

## 边界情况

| 场景 | 处理 |
|------|------|
| 时间段内无饮食记录 | daily_avg 各项 = 0，meal_distribution = {}，top_foods = []，summary = "暂无数据" |
| 某餐次无记录（如无 snack） | 该餐次不出现或 avg_calories = 0 |
| 日期格式不合法 | 返回 1002 |
| start_date > end_date | 返回 1002 |

---

## 错误码

| code | msg | 触发条件 |
|------|-----|----------|
| 0 | ok | 成功 |
| 1001 | 用户不存在 | user_id 不在 user_account 中 |
| 1002 | 参数校验失败：{具体原因} | 日期格式/范围不合法 |
