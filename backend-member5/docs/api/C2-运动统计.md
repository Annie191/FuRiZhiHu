# C2 — 运动统计

## 基本信息

| 项目 | 说明 |
|------|------|
| 方法 | `GET` |
| 路径 | `/api/statistics/{user_id}/sport` |
| 功能 | 统计指定时间段内运动数据：总时长、按类型分布、每日趋势、完成率 |
| 鉴权 | 无 |

---

## 请求参数

| 字段 | 类型 | 必填 | 位置 | 说明 |
|------|------|------|------|------|
| user_id | int | ✅ 是 | Path | 用户编号 |
| start_date | string | ✅ 是 | Query | 起始日期 `YYYY-MM-DD` |
| end_date | string | ✅ 是 | Query | 结束日期 `YYYY-MM-DD` |

### 请求示例

```text
GET /api/statistics/1/sport?start_date=2026-07-10&end_date=2026-07-17
```

---

| data | object | 统计数据 |

| data.period.start | string | 起始日期 |
| data.period.end | string | 结束日期 |
| data.total_duration_min | int | 运动总时长（分钟） |

| data.active_days | int | 有运动的天数 |
| data.sport_breakdown | object | 按运动类型分布 |
| data.sport_breakdown.{sport_type} | object | 以运动类型名称为 key |

## 业务逻辑

```
1. 参数校验
2. 查 v_daily_sport_summary 获取每日汇总 → duration_trend + 总时长
3. 查 sport_record GROUP BY sport_type 获取按类型分布
4. 计算 active_days（duration > 0 的天数）
5. 计算 completion_rate = active_days / 总天数 × 100
6. 生成 summary
```

### SQL（2 条查询）

```sql
-- 查询1：每日运动汇总
SELECT record_date, total_duration_min, total_calories_burned, sport_times
FROM v_daily_sport_summary
WHERE user_id = ? AND record_date BETWEEN ? AND ?
ORDER BY record_date;

-- 查询2：按运动类型分布
SELECT sport_type,
       SUM(duration_min) AS total_min,
       COUNT(*) AS cnt,
       ROUND(SUM(calories_burned), 2) AS total_cal
FROM sport_record
WHERE user_id = ? AND record_date BETWEEN ? AND ?
GROUP BY sport_type;
```

## 数据来源

| 数据 | 来源 |
|------|------|
| 每日运动汇总 | `v_daily_sport_summary` 视图 |
| 运动类型分布 | `sport_record` 原始表 |

---

## 边界情况

| 场景 | 处理 |
|------|------|
| 时间段内无运动记录 | total_duration_min = 0, active_days = 0, completion_rate = 0, sport_breakdown = {}, summary = "暂无数据" |
| 某天有运动但 v_daily_sport_summary 未汇总 | 不会发生——视图实时聚合原始表 |
| 日期格式不合法 | 返回 1002 |

---

## 错误码

| code | msg | 触发条件 |
|------|-----|----------|
| 0 | ok | 成功 |
| 1001 | 用户不存在 | user_id 不在 user_account 中 |
| 1002 | 参数校验失败：{具体原因} | 日期格式/范围不合法 |
