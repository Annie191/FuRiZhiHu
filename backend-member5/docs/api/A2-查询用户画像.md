# A2 — 查询用户画像

## 基本信息

| 项目 | 说明 |
|------|------|
| 方法 | `GET` |
| 路径 | `/api/profile/{user_id}` |
| 功能 | 根据 user_id 查询用户健康画像，含昵称（JOIN `user_account`） |
| 鉴权 | 无 |

---

## 请求参数

### Path

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| user_id | int | ✅ 是 | 用户编号，> 0 |

### 请求示例

```text
GET /api/profile/1
```

---

## 响应参数

### 成功响应（code = 0）

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 0 = 成功 |
| msg | string | 固定 `"ok"` |
| data | object | 画像数据 |
| data.user_id | int | 用户编号 |
| data.nickname | string | 昵称（来自 `user_account`） |
| data.age | int | 年龄 |
| data.gender | string | `male` / `female` / `other` |
| data.height_cm | float | 身高（厘米） |
| data.weight_kg | float | 体重（公斤） |
| data.bmi | float | BMI（数据库自动计算） |
| data.goal | string | `lose_fat` / `maintain` / `gain_muscle` |
| data.activity_level | string | `low` / `medium` / `high` |
| data.avg_sleep_hours | float | 平均睡眠时长（小时） |
| data.profile_tag | string | 用户标签 |
| data.water_target_ml | int | 每日饮水目标（毫升） |
| data.created_at | string | 创建时间 |
| data.updated_at | string | 更新时间 |

### 成功响应示例

```json
{
  "code": 0,
  "msg": "ok",
  "data": {
    "user_id": 1,
    "nickname": "张同学",
    "age": 22,
    "gender": "male",
    "height_cm": 175.0,
    "weight_kg": 70.0,
    "bmi": 22.86,
    "goal": "lose_fat",
    "activity_level": "low",
    "avg_sleep_hours": 6.5,
    "profile_tag": "夏季减脂型",
    "water_target_ml": 2200,
    "created_at": "2026-07-11 08:00:00",
    "updated_at": "2026-07-11 08:00:00"

```

### 错误响应示例

**画像不存在：**
```json
{
  "code": 1001,
  "msg": "用户画像不存在，请先创建画像",
  "data": null
}
```

---

## 业务逻辑

```
1. JOIN user_account + user_profile 查询
2. 结果为空 → 返回 1001
3. 结果存在 → 组装返回
```

### SQL

```sql
SELECT
    ua.user_id, ua.nickname,
    up.age, up.gender, up.height_cm, up.weight_kg, up.bmi,
    up.goal, up.activity_level, up.avg_sleep_hours,
    up.profile_tag, up.water_target_ml,
    up.created_at, up.updated_at
FROM user_account ua
INNER JOIN user_profile up ON up.user_id = ua.user_id
WHERE ua.user_id = ?
```

---

## 数据来源

| 数据 | 来源 |
|------|------|
| user_id, nickname | `user_account` |
| 画像所有字段 | `user_profile` |

---

## 边界情况

| 场景 | 处理 |
|------|------|
| user_id 存在但无画像 | 返回 1001（需先创建画像） |
| user_id 不存在 | 返回 1001（画像不存在） |

---

## 错误码

| code | msg | 触发条件 |
|------|-----|----------|
| 0 | ok | 成功 |
| 1001 | 用户画像不存在，请先创建画像 | 无画像 |
