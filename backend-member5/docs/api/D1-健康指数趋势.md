# D1 — 健康指数趋势

## 基本信息

| 项目 | 说明 |
|------|------|
| 方法 | `GET` |
| 路径 | `/api/trend/{user_id}/health-score` |
| 功能 | 分析近 N 天健康指数变化趋势，基于 numpy 线性回归判断上升/下降/平稳 |
| 鉴权 | 无 |

---

## 请求参数

| 字段 | 类型 | 必填 | 位置 | 说明 |
|------|------|------|------|------|
| user_id | int | ✅ 是 | Path | 用户编号 |
| days | int | 否 | Query | 统计天数，默认 30，范围 7~90 |

### 请求示例

```text
GET /api/trend/1/health-score?days=30
```

**使用默认值：**
```text
GET /api/trend/1/health-score
```

## 业务逻辑

```
1. 参数校验：days 在 7~90 之间
2. 计算日期范围：end_date = 今天，start_date = end_date - days
3. 查 v_dashboard_daily 获取范围内每日 health_score
4. 有效数据 < 7 天 → trend = "数据不足"，slope = null，不执行回归
5. numpy 线性回归：
   x = [0, 1, 2, ...]（天数索引）
   y = [score1, score2, ...]（健康指数序列）
   slope, intercept = np.polyfit(x, y, 1)
6. 趋势判定：
   - slope > 0.5  → "上升"
   - slope < -0.5 → "下降"
   - 否则        → "平稳"
7. 统计 current/avg/max/min/change
8. 返回
```

### SQL（1 条查询）

```sql
SELECT stat_date, health_score
FROM v_dashboard_daily
WHERE user_id = ? AND stat_date BETWEEN ? AND ?
ORDER BY stat_date;
```

---

## 趋势判定阈值

| 条件 | trend |
|------|-------|
| slope > 0.5 | 上升（持续改善） |
| -0.5 ≤ slope ≤ 0.5 | 平稳（基本不变） |
| slope < -0.5 | 下降（持续恶化） |
| 有效数据 < 7 天 | 数据不足 |

> 阈值 0.5 的含义：每天健康指数平均变化 0.5 分以上才判定为有趋势。避免小波动被误判。

---

## 数据来源

| 数据 | 来源 |
|------|------|
| 每日健康指数 | `v_dashboard_daily` 视图 |
| 趋势计算 | Python `numpy.polyfit` |

---

## 边界情况

| 场景 | 处理 |
|------|------|
| days < 7 或 > 90 | 返回 1002 |
| 有效数据 < 7 天（如新用户） | trend = "数据不足"，slope = null，仍返回已有统计 |
| 范围内无数据 | chart_data = []，trend = "数据不足"，current/avg/max/min = 0 |
| 全部健康指数相同 | slope ≈ 0，trend = "平稳" |

---

## 错误码

| code | msg | 触发条件 |
|------|-----|----------|
| 0 | ok | 成功 |
| 1001 | 用户画像不存在 | user_id 无画像 |
| 1002 | 参数校验失败：days 应在 7~90 之间 | days 超出范围 |
