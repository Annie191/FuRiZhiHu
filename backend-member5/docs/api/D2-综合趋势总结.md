# D2 — 综合趋势总结

## 基本信息

| 项目 | 说明 |
|------|------|
| 方法 | `GET` |
| 路径 | `/api/trend/{user_id}/summary` |
| 功能 | 一次性返回近 N 天所有维度（健康指数、饮水、运动、睡眠、饮食）趋势分析 + 综合评语 |
| 鉴权 | 无 |

---

## 请求参数

| 字段 | 类型 | 必填 | 位置 | 说明 |
|------|------|------|------|------|
| user_id | int | ✅ 是 | Path | 用户编号 |
| days | int | 否 | Query | 统计天数，默认 30，范围 7~90 |

### 请求示例

```text
GET /api/trend/1/summary?days=30
```

## 业务逻辑

```
1. 参数校验：days 在 7~90 之间
2. 查 user_profile 获取用户画像（goal 用于评语个性化）→ 不存在返回 1001
3. 计算日期范围
4. 一次性查 v_dashboard_daily（BETWEEN），获取所有维度每日数据
5. 有效数据 < 7 天 → 所有 trend = "数据不足"，返回通用提示
6. 对各维度数值序列分别执行 numpy 线性回归，判定趋势
7. 生成 overall_assessment：
   a. 健康指数趋势判断（上升/下降/平稳）
   b. 找出改善的维度（trend = "上升"）
   c. 找出需关注的维度（trend = "下降"）
   d. 拼接成自然语言
8. 返回
```

### SQL（2 条查询）

```sql
-- 查询1：用户画像
SELECT goal FROM user_profile WHERE user_id = ?;

-- 查询2：一次性获取全维度每日数据
SELECT stat_date, health_score, water_ml, sport_duration_min,
       food_health_score, sleep_hours, sleep_quality_score
FROM v_dashboard_daily
WHERE user_id = ? AND stat_date BETWEEN ? AND ?
ORDER BY stat_date;
```

### 趋势判定（同 D1）

```python
def calc_trend(values):
    x = np.arange(len(values))
    y = np.array(values)
    slope, _ = np.polyfit(x, y, 1)
    if slope > 0.5:   return "上升"
    elif slope < -0.5: return "下降"
    else:              return "平稳"
```

### 综合评语生成规则

| 健康指数趋势 | 评语片段 |
|-------------|---------|
| 上升 | "近N天健康状态整体向好" |
| 下降 | "近N天健康状态有所下滑" |
| 平稳 | "近N天健康状态保持平稳" |

| 维度趋势 | 评语片段 |
|---------|---------|
| 运动 trend = 上升 | "运动习惯明显改善" |
| 饮水 trend = 上升 | "饮水习惯有所进步" |
| 睡眠 trend = 下降 | "睡眠质量波动较大，是当前最需要关注的维度" |
| 饮食 trend = 下降 | "饮食健康度有所下滑，建议关注" |

## 边界情况

| 场景 | 处理 |
|------|------|
| 画像不存在 | 返回 1001 |
| days < 7 或 > 90 | 返回 1002 |
| 有效数据 < 7 天 | 所有 trend = "数据不足"，overall_assessment 提示继续记录 |
| 范围内无数据 | 同上 |
| 某维度全为 0（如无运动记录） | 该维度 avg = 0，trend = "平稳" |
| 所有维度都平稳 | 评语："近N天健康状态保持平稳，各维度无明显变化" |
