# B2 — 每周健康报告

## 基本信息

| 项目 | 说明 |
|------|------|
| 方法 | `GET` |
| 路径 | `/api/report/{user_id}/weekly` |
| 功能 | 汇总一周（或指定时间段）内每日健康数据，输出评分趋势、各维度汇总和自然语言总结 |
| 鉴权 | 无 |

---

## 请求参数

| 字段 | 类型 | 必填 | 位置 | 说明 |
|------|------|------|------|------|
| user_id | int | ✅ 是 | Path | 用户编号 |
| start_date | string | 否 | Query | 起始日期 `YYYY-MM-DD`，默认 7 天前 |
| end_date | string | 否 | Query | 结束日期 `YYYY-MM-DD`，默认昨天 |

### 请求示例

```text
GET /api/report/1/weekly?start_date=2026-07-10&end_date=2026-07-17
```

**缺省参数（使用默认值）：**
```text
GET /api/report/1/weekly
```

## 业务逻辑

```
1. 参数处理：
   - end_date 传了就用，没传默认昨天
   - start_date 传了就用，没传默认 end_date - 7 天
   - 校验 start_date ≤ end_date

2. 查 user_profile 确认画像存在 → 不存在返回 1001

3. 一次性查 v_dashboard_daily（BETWEEN start_date AND end_date）
   - 获取每日 health_score, water_ml, sport_duration_min, food_health_score, sleep_hours, sleep_quality_score

4. 无数据 → score_trend = [], avg_health_score = 0, weekly_summary = "暂无数据"

5. 逐维度汇总：
   - water：avg_ml, best_day（MAX）, worst_day（MIN）
   - sport：total_min（SUM）, active_days（>0 的天数）, best_day
   - food：avg_food_score，best_day
   - sleep：avg_hours, avg_quality，best_day（按 quality_score）

6. 生成 weekly_summary：
   "本周运动 {active_days} 天，共 {total_min} 分钟；日均饮水 {avg_ml}ml；平均睡眠 {avg_hours}h"
```

### SQL

```sql
SELECT d.stat_date, d.health_score, d.water_ml, d.sport_duration_min,
       d.food_health_score, d.sleep_hours, d.sleep_quality_score,
       up.water_target_ml
FROM v_dashboard_daily d
JOIN user_profile up ON up.user_id = d.user_id
WHERE d.user_id = ? AND d.stat_date BETWEEN ? AND ?
ORDER BY d.stat_date;
```

## 与 B1 的区别

| | B1（日报） | B2（周报） |
|------|-----------|-----------|
| 数据源 | `v_dashboard_daily` WHERE stat_date = ? | `v_dashboard_daily` WHERE stat_date BETWEEN ? AND ? |
| 返回维度 | 单日四维度详细拆解 | 多日趋势 + 汇总 |
| grade | ✅ 有 | ❌ 无（多日不适用） |
| summary | ❌ 无 | ✅ 自然语言总结 |

## 数据来源

| 字段 | 来源 |
|------|------|
| 每日健康数据 | `v_dashboard_daily` |
| water_target_ml | `user_profile` |

---

## 边界情况

| 场景 | 处理 |
|------|------|
| 画像不存在 | 返回 1001 |
| start_date > end_date | 返回 1002 |
| 时间段内无任何数据 | score_trend = [], avg_health_score = 0, weekly_summary = "暂无数据" |
| 时间段跨度为 1 天 | 正常返回（等价于日报汇总版） |
| 日期格式错误 | 返回 1002 |

---

## 错误码

| code | msg | 触发条件 |
|------|-----|----------|
| 0 | ok | 成功 |
| 1001 | 用户画像不存在，请先创建画像 | 画像不存在 |
| 1002 | 参数校验失败：{具体原因} | 日期格式/范围不合法 |
