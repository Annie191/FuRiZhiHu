# C4 — Dashboard 综合概览

## 基本信息

| 项目 | 说明 |
|------|------|
| 方法 | `GET` |
| 路径 | `/api/statistics/{user_id}/overview` |
| 功能 | 当日 Dashboard 总览——直接查询 `v_dashboard_daily`，返回健康指数 + 四维度任务完成情况 |
| 鉴权 | 无 |

> **说明**：`weather_notice`（天气风险）和 `today_suggestions`（每日建议）由成员4 的推荐规则模块负责。本接口只返回健康数据维度。

---

## 请求参数

| 字段 | 类型 | 必填 | 位置 | 说明 |
|------|------|------|------|------|
| user_id | int | ✅ 是 | Path | 用户编号 |
| date | string | ✅ 是 | Query | 日期 `YYYY-MM-DD` |

### 请求示例

```text
GET /api/statistics/1/overview?date=2026-07-17
```

---

## 响应参数

### 成功响应（code = 0）

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 0 = 成功 |

| data | object | 概览数据 |
| data.date | string | 日期 |
| data.health_score | float | 健康指数 0-100 |
| data.grade | string | 等级：`优秀` / `良好` / `一般` / `需改善` |
| data.task_completion | object | 四维度任务完成 |
| data.task_completion.water | object | 饮水 |
| data.task_completion.water.current_ml | int | 实际饮水（ml） |
| data.task_completion.water.target_ml | int | 目标饮水（ml） |
| data.task_completion.water.percent | float | 完成百分比，上限 100% |
| data.task_completion.sport | object | 运动 |
| data.task_completion.sport.current_min | int | 实际运动（分钟） |
| data.task_completion.sport.target_min | int | 目标运动，固定 30 分钟 |
| data.task_completion.sport.percent | float | 完成百分比，上限 100% |
| data.task_completion.food | object | 饮食 |
| data.task_completion.food.food_health_score | float | 饮食健康评分 0-100 |
| data.task_completion.food.percent | float | 等同于 food_health_score（满分 100） |
| data.task_completion.sleep | object | 睡眠 |
| data.task_completion.sleep.sleep_hours | float | 实际睡眠时长（小时） |
| data.task_completion.sleep.quality_score | float | 睡眠质量评分 0-100 |
| data.task_completion.sleep.percent | float | 等同于 quality_score（满分 100） |

## 业务逻辑

```
1. 查 user_profile 确认画像存在 → 不存在返回 1001
2. 查 v_dashboard_daily 获取当日数据
3. 计算每个维度的 percent（饮水/运动 cap 在 100%）
4. 组装返回
```

### SQL

```sql
SELECT d.health_score, d.water_ml, d.sport_duration_min,
       d.food_health_score, d.sleep_hours, d.sleep_quality_score,
       up.water_target_ml, up.profile_tag
FROM v_dashboard_daily d
JOIN user_profile up ON up.user_id = d.user_id
WHERE d.user_id = ? AND d.stat_date = ?;
```

---

## 与 B1 的关系

| | B1（每日报告） | C4（综合概览） |
|------|--------------|--------------|
| 返回内容 | 单日四维度详细拆解 + breakdown 权重 | 四维度完成百分比 + 等级 |
| 使用场景 | 健康报告详情页 | Dashboard 首页卡片 |
| 字段风格 | `water.actual`, `water.target`, `water.completion` | `water.current_ml`, `water.target_ml`, `water.percent` |
| 数据源 | 完全一致（`v_dashboard_daily` + `user_profile`） |

---

## 数据来源

| 字段 | 来源 |
|------|------|
| health_score 及各维度数据 | `v_dashboard_daily` |
| water_target_ml, profile_tag | `user_profile` |

---

## 边界情况

| 场景 | 处理 |
|------|------|
| 画像不存在 | 返回 1001 |
| 当日无任何记录 | health_score = 0, grade = "需改善"，各维度 current = 0 |
| 完成度超过 100% | percent 截断为 100 |

---

## 错误码

| code | msg | 触发条件 |
|------|-----|----------|
| 0 | ok | 成功 |
| 1001 | 用户画像不存在，请先创建画像 | 画像不存在 |
| 1002 | 参数校验失败：日期格式应为 YYYY-MM-DD | date 格式不合法 |
