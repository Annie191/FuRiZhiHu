# C3 — 睡眠统计

## 基本信息

| 项目 | 说明 |
|------|------|
| 方法 | `GET` |
| 路径 | `/api/statistics/{user_id}/sleep` |
| 功能 | 统计指定时间段内睡眠数据：日均时长/质量、入睡时间范围、每日趋势、质量分布 |
| 鉴权 | 无 |

---

## 请求参数

| 字段 | 类型 | 必填 | 位置 | 说明 |
|------|------|------|------|------|
| user_id | int | ✅ 是 | Path | 用户编号 |
| start_date | string | ✅ 是 | Query | 起始日期 `YYYY-MM-DD` |
| end_date | string | ✅ 是 | Query | 结束日期 `YYYY-MM-DD` |

### 请求示例

```text
GET /api/statistics/1/sleep?start_date=2026-07-10&end_date=2026-07-17
```

## 业务逻辑

```
1. 参数校验
2. 查 v_daily_sleep_summary 获取每日汇总（sleep_hours, sleep_quality_score）
3. 查 sleep_record 原始表获取最早/最晚入睡时间
4. 按 quality_score 分级统计 quality_distribution
5. 计算 avg_sleep_hours、avg_quality_score
6. 生成 summary
```

### SQL（2 条查询）

```sql
-- 查询1：每日睡眠汇总
SELECT record_date, sleep_hours, sleep_quality_score
FROM v_daily_sleep_summary
WHERE user_id = ? AND record_date BETWEEN ? AND ?
ORDER BY record_date;

-- 查询2：入睡时间范围
SELECT
    MIN(time(sleep_time)) AS earliest,
    MAX(time(sleep_time)) AS latest
FROM sleep_record
WHERE user_id = ? AND record_date BETWEEN ? AND ?;
```

### 质量等级划分

| 等级 | 条件 |
|------|------|
| excellent | quality_score ≥ 90 |
| good | 80 ≤ quality_score ≤ 89 |
| fair | 60 ≤ quality_score ≤ 79 |
| poor | 40 ≤ quality_score ≤ 59 |
| very_poor | quality_score < 40 |

---

## 数据来源

| 数据 | 来源 |
|------|------|
| 每日睡眠汇总（时长、质量） | `v_daily_sleep_summary` 视图 |
| 入睡/起床具体时间 | `sleep_record` 原始表 |

> `v_daily_sleep_summary` 中的 `sleep_hours` 已用 `julianday(wake_time) - julianday(sleep_time)` 自动处理跨天问题，Python 端无需手动计算。

---

## 边界情况

| 场景 | 处理 |
|------|------|
| 时间段内无睡眠记录 | avg_sleep_hours = 0, avg_quality_score = 0, earliest/latest = null, total_records = 0, summary = "暂无数据" |
| 只有 1 条记录 | earliest = latest = 同一天入睡时间 |
| 跨天睡眠（如 23:00 入睡到次日 7:00） | 数据库 `julianday` 自动计算正确时长 |
| 日期格式不合法 | 返回 1002 |

---

## 错误码

| code | msg | 触发条件 |
|------|-----|----------|
| 0 | ok | 成功 |
| 1001 | 用户不存在 | user_id 不在 user_account 中 |
| 1002 | 参数校验失败：{具体原因} | 日期格式/范围不合法 |
